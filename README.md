# Roskilde Ring for Omarchy

A dark, vintage motorsport-inspired theme: olive-green surfaces, warm paper-white
text, brass-gold accents, and racing-red highlights.

This is an independent community theme, not an official or endorsed Omarchy
theme, and is not affiliated with Roskilde Ring.

## Install

```sh
omarchy theme install https://github.com/uhansen/omarchy-roskilde-ring-theme.git
```

Installation applies the theme. To select it again:

```sh
omarchy theme set roskilde-ring
```

The theme uses Omarchy's `colors.toml` format. A current Omarchy installation
generates terminal, editor, shell, and application configurations from this
palette; no executable theme files or extensions are bundled.

## Palette

| Role | Color |
|------|-------|
| Background | `#20251c` |
| Foreground | `#e5dcc3` |
| Accent | `#d4b365` |
| Racing red | `#df7866` |
| Olive green | `#a5b779` |
| Blue | `#92adc0` |

## Wallpaper

No wallpaper is distributed. The historic poster artwork and photographs are
not included or covered by this repository's license.

To use your own locally held wallpaper, place a PNG or JPG in
`~/.config/omarchy/backgrounds/roskilde-ring/` before installing or applying the
theme. Omarchy will select a background from that directory. Without a
background, Omarchy applies the palette and reports that none was found.

To return to Tokyo Night:

```sh
omarchy theme set tokyo-night
```
